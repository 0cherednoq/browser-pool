# Руководство

Страницы собраны по проблемам: в начале каждой описана ситуация, дальше сказано, что с ней делает пул и как это настроить.

## Найти страницу по проблеме

| Если у вас… | Читайте |
|---|---|
| окна браузеров открываются друг на друге, непонятно, какое чьё, упавшая страница закрывается раньше, чем вы её увидели | [Отладка окон](debug.md) |
| семафоры на задачи, на аккаунты, на браузеры и своя очередь с приоритетами | [Параллельность](parallelism.md) |
| пять задач одного аккаунта логинятся одновременно, после перезапуска снова вход по паролю | [Вход](login.md) |
| по утрам десятки зависших Chrome, браузеры занимают всё больше памяти, машина уходит в своп | [Ресурсы хоста](resources.md) |
| мёртвые прокси, аккаунт каждый день с нового адреса, часовой пояс не совпадает со страной прокси | [Прокси](proxies.md) |
| `try/except` длиннее самой автоматизации, падение Chrome останавливает всё, повтор отправляет письмо дважды | [Сбои и повторы](recovery.md) |
| непонятно, что пул делает прямо сейчас и почему задачи стоят | [Наблюдение](observability.md) |
| логику повторов и пауз невозможно проверить без браузера и часов ожидания | [Тесты](testing.md) |
